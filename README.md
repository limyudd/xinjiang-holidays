专为苹果日历制作的简体中文新疆节日订阅源，包含 **肉孜节、古尔邦节**，无需改变 iPhone 的地区设置，也不会影响中国农历显示。

> 本项目是社区维护的日历，**不是苹果或新疆政府官方订阅源**。预测日期可能与当地正式日期相差 1–2 天，官方假期信息以自治区公告为准。

## 📱 iPhone 添加订阅教程

> 适用于使用 Apple 自带「日历」App 的用户；不同 iOS 版本的按钮名称可能略有差别。

### 方法一：直接从「日历」App 添加（推荐）

1. 打开 iPhone 系统自带的 **日历** App（不是「设置」）。
2. 点击屏幕底部 **「日历」**，进入日历列表。
3. 点击底部 **「添加日历」**。
4. 选择 **「添加订阅日历」**（注意：不是「添加节假日日历」）。
5. 把上面的 `.ics` 地址粘贴到 **订阅 URL**，点击 **「查找」** 或 **「订阅」**。
6. 名称可改为 **「新疆节假日」**，颜色建议选择绿色；如果出现账户选项，选择 **iCloud**，便于在其他 Apple 设备同步。
7. 点击 **「完成」**。返回日历列表，确认 **「新疆节假日」** 已勾选。

**操作路径速览**

```text
日历 App
  └─ 底部「日历」
       └─ 「添加日历」
            └─ 「添加订阅日历」
                 └─ 粘贴 .ics 地址
                      └─ 查找/订阅 → 完成
```

### 方法二：从系统设置添加

部分 iOS 版本也可以通过 **设置 → App → 日历 → 日历账户 → 添加账户 → 其他 → 添加已订阅的日历** 输入同一个 URL。如果你找不到相应入口，优先使用方法一。

### 常见问题

**Q：我的 iPhone 地区是美国，还能订阅吗？**  
可以。订阅 ICS 与 iPhone 所选地区没有直接关系，不需要切换地区，也不会影响已有的中国农历设置。

**Q：为何没有「添加节假日日历」选项？**  
本项目使用的是 **「添加订阅日历」**，这两个入口不同。

**Q：为什么看不到新节日或改过的标题？**  
先在「日历」App 底部的日历列表里确认订阅已勾选。Apple 订阅日历的刷新可能存在缓存和延迟；可稍后再查看。**不要通过下载 ICS 后选择「导入事件」来代替订阅**，否则可能只导入一次，无法持续自动同步。

**Q：是否显示苹果中国大陆地区原生的「休 / 班」角标？**  
不能。第三方 ICS 会以普通全天事件显示，不支持控制苹果系统原生角标。

**Q：显示为预测日期还是官方日期？**  
日历标题统一简写为「肉孜节」「古尔邦节」，点击事件可在说明中查看是伊斯兰历推算还是新疆官方确认。官方假期采用跨天全天事件。

## 🛠️ 仓库部署（维护者）

1. Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**，Folder: **/docs**。
2. Actions → **更新新疆节假日日历** → Run workflow，首次运行后生成 `docs/xinjiang.ics`。
3. 若工作流没有写入权限，检查 Settings → Actions → General 中的 Workflow permissions 是否支持 **Read and write permissions**。

## 🔄 更新策略

- GitHub Actions 每日检查并重新生成未来约 15 年的节日日历。
- `generate.py` 使用伊斯兰民用表算历预测日期；**预测不是官方确认**。
- `official.json` 保存已确认的节日日期和新疆放假区间，优先于预测值。
- `sync_official.py` 尝试从新疆自治区政府通知公告列表发现下一年度正式放假通知；只有能够可靠提取节日与假期区间时才会校正。网站结构变化或识别不确定时会跳过，仍需人工核验。
- 已订阅用户无须每年重新添加日历，实际刷新速度由 iOS 决定。

2026 年官方依据：[新疆维吾尔自治区人民政府放假通知](https://www.xinjiang.gov.cn/xinjiang/tzgg/202512/aaece21b6906443e8d50b981070764a8.shtml)。
